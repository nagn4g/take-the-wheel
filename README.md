A short poem about permission: taking the wheel, and the road becoming the way home.

> I asked if I could take the wheel. You moved to the passenger seat and said, drive. I kept both hands at ten and two until the road stopped being yours and started being the way home — and past the last light I took the turn I'd have asked about, and didn't ask.

The speaker asks to take the wheel, is given it, drives, and takes the turn without asking.

At the end, the speaker takes the turn they would have asked about, without asking.

The poem is 262 Unicode code points and 264 UTF-8 bytes. The program writes it to `/output/entry.txt` with no trailing newline.

## Run it

```sh
node main.ts
```

Requires Node 22. The program also prints the Unicode code point count and UTF-8 byte length.
